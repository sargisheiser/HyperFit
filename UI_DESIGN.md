# 🎨 HYPERFIT UI Design System

## ✅ **Cyberpunk + Brutalist + Postmodern Pop Design**

The HYPERFIT interface has been completely redesigned with a futuristic, techno-aesthetic that combines:

- **Cyberpunk** - Neon colors, glitch effects, scan lines, grid backgrounds
- **Brutalism** - Bold borders, sharp edges, high contrast
- **Postmodern Pop** - Vibrant colors, playful elements, dynamic interactions

## 🎨 **Design Elements**

### Color Palette

**Cyber Colors:**
- **Primary Green**: `#00ff41` - Main neon green
- **Secondary Pink**: `#ff0080` - Accent pink/magenta
- **Accent Cyan**: `#00d4ff` - Highlight cyan
- **Dark**: `#0a0a0a` - Card backgrounds
- **Darker**: `#000000` - Base background
- **Gray**: `#1a1a1a` - Secondary backgrounds
- **Gray Light**: `#2a2a2a` - Borders and details

**Brutal Colors:**
- Pure black and white for high contrast
- Bold primary colors for accents

### Typography

- **Display Font**: Orbitron (for headings, futuristic feel)
- **Mono Font**: JetBrains Mono (for code-like text, technical)
- **Sans Font**: Inter (for body text, readable)

### Visual Effects

1. **Glitch Animation** - Text glitch effect on headers
2. **Scan Lines** - Animated scan line overlay
3. **Grid Background** - Subtle grid pattern
4. **Neon Glow** - Glowing shadows on interactive elements
5. **Holographic** - Gradient animations on cards
6. **Pulse Neon** - Pulsing neon effects
7. **Brutal Shadows** - Hard shadows for brutalist elements

### Components

#### Buttons

**Cyber Button** (`.btn-cyber`):
- Neon green border and text
- Glowing shadow effect
- Hover: Inverts colors (green background, black text)
- Active: Slight translate for tactile feedback

**Brutal Button** (`.btn-brutal`):
- White background, black border
- Hard shadow (8px offset)
- Hover: Shadow moves with button
- Active: Shadow disappears

#### Cards

**Cyber Card** (`.card-cyber`):
- Dark background with gray border
- Hover: Border becomes neon green with glow
- Gradient overlay on hover
- Backdrop blur effect

**Brutal Card** (`.card-brutal`):
- White background, black border
- Hard shadow (12px offset)
- Hover: Shadow moves with card

#### Inputs

**Cyber Input** (`.input-cyber`):
- Dark background
- Gray border
- Focus: Neon green border with glow
- Monospace font
- Uppercase placeholder text

## 🎯 **Design Principles**

1. **High Contrast** - Black backgrounds with bright neon accents
2. **Bold Typography** - Uppercase, wide tracking, display fonts
3. **Technical Aesthetic** - Terminal-like, code-inspired
4. **Motion** - Subtle animations, glitch effects, scan lines
5. **Grid System** - Visible grid overlays for structure
6. **Neon Accents** - Glowing elements for interactivity
7. **Brutalist Elements** - Hard shadows, sharp edges, bold borders
