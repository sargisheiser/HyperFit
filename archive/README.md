# Archive Directory

Dieser Ordner enthält nicht mehr relevante Dateien, die aus dem Hauptprojekt verschoben wurden.

## Struktur

- **docs/**: Alte Dokumentationsdateien (.md)
- **scripts/**: Alte/veraltete Shell-Skripte
- **old_migrations/**: Alte Datenbank-Migrationsskripte
- **temp/**: Temporäre Dateien und seltsame Dateien

## Hinweis

Diese Dateien werden für Referenzzwecke aufbewahrt, sollten aber nicht mehr im aktiven Projekt verwendet werden.
